# Design System Configuration

This directory contains design tokens that govern video styling, visual consistency, and branding across renders.

- `palette.json`: Defines color tokens for both dark and light modes, including background, surface, primary, secondary, accent, and overlay values.
- `typography.json`: Specifies font families, font weights, size scales, and line heights for headings, body text, code snippets, and captions.

## Customization
Creators can customize these files to align with their visual brand while preserving consistent component layout.
