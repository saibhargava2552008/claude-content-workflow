# Video Planning Guide

A structured guide for planning high-retention short-form vertical videos.

## 1. The Hook (0 - 3 seconds)
- Grab attention immediately with a visual pattern interrupt or a provocative question.
- Avoid slow intros or lengthy greetings. State the core value proposition instantly.

## 2. Core Narrative & Value (3 - 45 seconds)
- Break explanation into distinct cognitive beats (2–5 seconds per visual shift).
- Match every spoken concept with a corresponding visual cue: title, code block, diagram, or b-roll cut.
- Maintain high information density without visual clutter.

## 3. Climax & Resolution
- Deliver on the promise made in the hook.
- Summarize actionable takeaways.

## 4. Call to Action (CTA)
- Keep CTAs short (3–5 seconds), clear, and natural.
